# Fastenly

Go-to-market pack for selling a **private multi-workflow automation desk** to any team drowning in repeat work.

Working brand: **Fastenly**. Automation desks: **Basic £795 · Gold £1,095 · Premium £1,495**. Full websites (no automation required): **£4,000 · £4,500 · £5,000**. Hosting **£49/mo** or **Priority £129/mo** (+£80).

This repo is intentionally separate from any client production app. Do not put customer data here.

## Positioning

Fastenly is **not** a single-industry tool and **not** one converter. It is a company-private desk where many automations stack:

- Messy text / documents → clean sheets  
- Field & quality checks  
- Format normalisers  
- Multi-source merges  
- Chase lists & report packs  
- Custom repeat workflows once samples exist  

Lead with the desk. Common first modules: Excel text parse (custom layout), reports from dumps, delivery boards, or a private / public site — never pitch one trick as the whole product.

## Quick start

1. Find-replace `YOU@EXAMPLE.com` with your real email; add Calendly + Loom links.
2. Open `landing.html` — use **See how it runs**, then the live desk.
3. Host on Netlify Drop / Cloudflare Pages / any static host.
4. Book a recurring **Open Desk Hour** and follow `gtm-process.md` for one full week before changing the offer.
5. Seed `targets.csv` (~40 firms); prefer hiring-signal hooks; send ~10 LinkedIn notes/day.

## Boundaries

- Sell a **new** private build per customer.
- Prefer paid pilots over free “full platform” builds.
- Keep real customer data out of this marketing repo.
- Landing parse panel is one interactive example — production modules are scoped per customer.
