# Hauldesk

Go-to-market pack for selling **job-sheet → Excel** desks to UK vehicle transport teams.

Working brand: **Hauldesk**. Pilot offer: **£2,500 + £149/mo hosting**.

This repo is intentionally separate from any client production app. Do not put customer job data here.

## Contents

| File | Use |
|------|-----|
| `landing.html` | One-page site — replace `YOU@EXAMPLE.com` then host anywhere |
| `linkedin-outreach.md` | Connection notes + follow-ups |
| `email-outreach.md` | Cold email templates |
| `pilot-proposal.md` | Send after a good discovery call |
| `targets.csv` | Track ~40 firms you contact |

## Quick start

1. Find-replace `YOU@EXAMPLE.com` with your real email (and optional Calendly on the landing CTAs).
2. Open `landing.html` locally, then host on Netlify Drop / Cloudflare Pages / any static host.
3. Record a 45s Loom with **redacted** sample job text only.
4. Fill `targets.csv` and send ~10 personalised LinkedIn notes per day.

## Boundaries

- Sell a **new** private build per customer — not access to another client’s system.
- Prefer paid pilots over free “full SaaS” builds.
- Keep real customer formats and data out of this marketing repo.
